# Drop folder

Put any file here: a PDF, a photo of a receipt, a document, a text file, a web link (`.url`). Your chief files one file at a time, about every 30 minutes:

- the text is saved under `raw/`, and the file itself under `raw/originals/`;
- what it says is added to the wiki, the daily note and the index.

Files it can't handle safely (too large, a `.zip`, unreadable, or needing a paid service or a download) go to `needs-review/` with a note saying why. Nothing is deleted. This README is never filed.
