## For future agent
How task notes work here. A task note holds the context for one card on a board; the card links to it, and both always agree on due date and status.

# Task notes

One note per task that needs more than a line: properties `type: task`, `status` (open, in-progress, waiting, done, cancelled), `priority` (🔴 🟡 🟢), `due: YYYY-MM-DD` and `board: "[[boards/Board name]]"`, then the context, the steps and what it's waiting on. Template: `templates/Task.md`.
